# Notebooks

Create your own EDA and experiment notebooks here. Recommended order:

1. `01_data_audit_eda.ipynb` — shapes, dtypes, target prevalence, missingness, distributions, category frequencies, correlations, and column-description review.
2. `02_baseline_comparison.ipynb` — reproduce the course baseline and compare with the scripted pipeline using an identical split.
3. `03_feature_experiments.ipynb` — test feature groups one at a time.
4. `04_model_selection.ipynb` — compare model families and (if feasible) cross-validation.

The original course `tutorial.ipynb` is retained in `input/` unchanged as reference material.
