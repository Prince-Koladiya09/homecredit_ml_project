# Project plan

| Phase | Deliverable | Exit criterion |
|---|---|---|
| 1. Requirements | Competition checklist | Rules, metric and submission schema understood |
| 2. Data audit | Profile + EDA notebook | Data quality and target imbalance documented |
| 3. Design | Validation/model plan | Split and leakage controls agreed |
| 4. Baseline | Reproducible baseline | Validation metric and artifacts saved |
| 5. Features | Feature experiment log | Each feature group tested fairly |
| 6. Model selection | Comparison table | Selected model justified by evidence |
| 7. Release | Submission + code archive | CSV checks pass and run is reproducible |
